M365 OWA Sync (Contacts + Calendar)

Syncs M365 business account calendar + contacts via Outlook on the web internal endpoints. Strategy ported from m365-owa-cli. No Azure app registration / OAuth — you capture an OWA bearer token from your browser.

1. Connection

Enter the host (origin) only — no path. The token must be captured from the SAME host. Examples: https://outlook.office.com, https://outlook.office365.com, https://outlook.cloud.microsoft. A pasted URL like https://outlook.cloud.microsoft/mail is auto-stripped to its origin.

2. Auto-refresh token (recommended)

The addon automatically gets fresh access tokens using Thunderbird's built-in OAuth2 system. Select your M365 account below — the mail server config is auto-detected from your existing Thunderbird mail account.

3. Capture OWA bearer token (manual fallback)

Generate a bookmarklet, save it as a bookmark, open Outlook on the web in your browser (logged in), then click the bookmark. It copies your token to the clipboard and shows it. Paste it below.
